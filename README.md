## Featured Projects

### Therawork - Appointment Scheduling System
A web application for organizing ministry appointments with local storage. It detects scheduling conflicts and classifies them by host, guest, location, or documents using color coding. Includes filters and advanced search features to reduce scheduling errors.

**Tech:** HTML, CSS, JavaScript

### School Management System
A complete web application with multiple roles: administration, academic supervisors, and teachers. Teachers submit weekly lesson plans with detailed explanations and teaching aids. Supervisors receive notifications to evaluate teachers and the schedule. The system automatically moves schedules between weeks, prevents double-booking and weekend scheduling, sends notifications, and supports PDF export with school name, logo, date, and class. It also manages student financial records, discounts, payments, remaining balances, and Excel/JSON import/export.

**Tech:** PHP, MySQL, JavaScript, HTML, CSS

### PlayHour - Child Center Management System
A database-driven web application for a child center. It includes admin and employee accounts, child session management with live timers, pricing, deferred payments, billing cancellation, payment confirmation, profit calculation, bookings, advanced search, Excel export, and database space monitoring.

**Tech:** PHP, MySQL, JavaScript, HTML, CSS
