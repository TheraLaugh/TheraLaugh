## مشاريع مميزة

### Therawork - نظام تنظيم المواعيد
تطبيق ويب لتنظيم مواعيد الوزارات مع تخزين محلي. يكشف التضارب في المواعيد ويصنفها حسب المستضيف أو المستضاف أو المكان أو الوثائق باستخدام نظام ألوان. يتضمن فلاتر وميزات بحث متقدمة لتقليل أخطاء التنظيم.

**التقنيات:** HTML, CSS, JavaScript

### نظام إدارة مدرسة
تطبيق ويب متكامل بأدوار متعددة: إدارة، مشرفون أكاديميون، ومعلمون. يقوم المعلمون بإدخال البرنامج الأسبوعي مع شرح وافٍ ووسائل تعليمية. يتلقى المشرفون إشعارات لتقييم المعلمين والجدول. ينقل النظام الجداول تلقائياً بين الأسابيع، ويمنع التضارب وحصص أيام العطلة، ويرسل الإشعارات، ويدعم تصدير PDF مع اسم المدرسة والشعار والتاريخ والصف. كما يدير السجلات المالية للطلاب والخصومات والمدفوعات والمتبقي، مع استيراد وتصدير Excel و JSON.

**التقنيات:** PHP, MySQL, JavaScript, HTML, CSS

### PlayHour - نظام إدارة مركز أطفال
تطبيق ويب مربوط بقاعدة بيانات لمركز أطفال. يتضمن حسابات للإداريين والموظفين، إدارة جلسات الأطفال مع عدادات وقت حية، التسعير، الدفع المؤجل، إلغاء الفوترة، تأكيد الدفع، احتساب الأرباح، الحجوزات، بحث متقدم، تصدير Excel، ومراقبة مساحة قاعدة البيانات.

**التقنيات:** PHP, MySQL, JavaScript, HTML, CSS
